# Voxel Sky Fighter

[English](README.md) | **简体中文**

在无限延伸的方块世界里驾驶飞机：从机场起飞，迎击一波波敌机，穿过金环，再飞回来降落。
画面保留方块风格，同时加入了接近写实的光照、天气和水面效果。

纯浏览器运行，无需构建：所有贴图、音效和音乐都由代码实时生成，只依赖 [three.js](https://threejs.org/)（通过 CDN 加载）。

## 运行

需要 Python 3 和一个支持 WebGL 2 的浏览器。

```bash
python3 serve.py
```

然后打开 <http://localhost:8765/>，点击画面开始。

`serve.py` 关闭了浏览器缓存，修改代码后刷新页面即可生效。也可以用任何静态文件服务器，但那样可能读到旧版本的模块。

在网址后加 `?debug` 会显示帧率、绘制调用和区块数的调试面板，并在控制台暴露 `window.__game`。用 `?debug&selftest` 还会快进跑一遍起飞、战斗、波次、自动降落、坠毁、自由飞行、机型手感、各类任务和 Boss，并在控制台输出结果（也可以手动调用 `__game.selfTest()`）。

`serve.py` 同时提供一个内存版的 `/api/leaderboard`，本地也能试用排行榜；服务器停止后分数会清空。

## 模式

- **Start Mission**：分关卡的战役，普通波次和任务交替出现，每第 5 关是 Boss。被击落时分数会提交到排行榜。
- **Free Flight**：自由飞行，没有敌人也不会结束；坠毁后直接回到空中。
- **世界种子**：在标题画面输入数字（或点 Random）换一个世界。种子也写在网址里（`?seed=123`），可以把链接发给别人飞同一个世界。
- **拍照模式**：飞行中按 **O** 冻结画面并用自由镜头取景；按 **K** 保存 PNG。

## 战役

| 关卡 | 内容 |
| --- | --- |
| 1、3、6、8 …… | 一波敌机，外加奖励圆环和热气球 |
| 2、4、7、9 …… | 任务，按下面四种轮换 |
| 5、10、15 …… | Boss：空中要塞飞艇 |

- **对地打击**：在时限内摧毁一支卡车车队和护卫的高射炮。
- **竞速穿环**：在时限内穿过 8 个蓝色圆环。
- **护航**：保护绿色运输机飞到目的地；大部分敌机会攻击它而不是你。
- **反舰**：击沉所有敌方军舰（附近没有海的世界会改为对地打击）。
- **空中要塞**：先打掉炮位；炮位全毁之前引擎有装甲，之后要塞会放出无人机。两台引擎都被摧毁后它会坠落。

完成任务有奖励分（剩余时间越多、运输机剩余耐久越高，奖励越多）；失败没有奖励，战役继续。

**难度**（简单 / 普通 / 困难，在 Game 设置里）影响敌人数量、开火频率和命中率，以及你的耐久。得分分别乘以 0.8、1、1.3，保证排行榜公平。修改从下一局开始生效。

**天气影响飞行**：风会让飞机偏移，雨和雷暴会造成颠簸；雷暴中飞到离地 100 米以上会被闪电击中，每次掉一颗心；雾会缩短导弹锁定距离。自由飞行模式可以关闭这些影响。

## 机型

每款飞机的速度、转向、耐久（心数）和导弹数都不同；在标题画面的机库里切换，会显示对比条。Standard 保持原来的手感。

新玩家一开始可以用 Standard、Brick Biplane 和 Super Mario，其余机型用生涯积分（所有战役得分的累计）解锁：Air Show 5,000，Brick Seaplane 10,000，F-16 Style 20,000，Brick Jet 35,000，Brick Airliner 50,000，Brick Storm 75,000。

## 排行榜

每个浏览器会分配一个随机的街机风格飞行员名字（可在标题画面重新随机）。每打完一局都会作为一条记录提交，包含分数、到达的波次、世界种子和日期；榜上只保留最高的 10 条，同一个飞行员可以占多个名次。你自己的记录显示为绿色，刚打完的那一局会高亮。

分数由 `api/leaderboard.js` 这个无服务器函数保存，需要在 Vercel 项目上连接一个 [Upstash Redis](https://vercel.com/marketplace/upstash) 数据库（读取 `KV_REST_API_URL` 和 `KV_REST_API_TOKEN`）。没有配置或离线时，游戏改为显示本浏览器自己的成绩。

分数由浏览器上报，服务器只能拒绝明显不合理的数值，挡不住刻意作弊。

## 操作

| 按键 | 作用 |
| --- | --- |
| 鼠标 | 操纵飞机（虚拟摇杆） |
| W / S | 拉起 / 俯冲 |
| A / D | 转向 |
| Q / E | 方向舵 |
| 左键 / 空格 | 机炮 |
| 右键 / F | 导弹（需要先锁定目标） |
| Shift | 地面加速 / 空中加力 |
| 滚轮、T / G | 巡航油门（松手后保持） |
| B | 减速板 |
| Z / C | 横滚 |
| X | 筋斗 |
| P | 开关自动降落 |
| O | 拍照模式（WASD 移动、Q/E 升降、滚轮缩放、K 保存） |
| H | 显示 / 隐藏按键说明 |
| Esc | 暂停 |
| 按住 R | 重新开始 |

在跑道上按住 Shift 加速，速度够了按 W 拉起。低速对准跑道降落可以修复机体并获得奖励。

## 内容

- **世界**：无限生成的方块地形，包含平原、森林、沙漠、雪原、山地、针叶林和海洋；村庄、风车、灯塔、金字塔、高塔等地标；鸟群、海上的船、机场车辆、村庄炊烟。
- **战斗**：逐波增强的敌人（冲撞机、炮艇、王牌机、地面炮塔、热气球），四种任务，每 5 关一艘 Boss 飞艇，机炮、可锁定的追踪导弹、特技与穿环加分。
- **机型**：9 款可选，包括 4 款积木玩具风格的飞机，每款手感不同，大部分需要通过游戏解锁。
- **画面**：动态昼夜和月相，晴、多云、雨、雷暴、雾五种天气（可自动切换），体积光、镜头光晕、彩虹、极光，水面倒影，级联阴影，环境光遮蔽，泛光，方块材质的凹凸与高光。
- **画质**：低、中、高、极高四档，并会根据帧率自动调整分辨率。体积光、水面倒影、雨和闪电、环境生物、速度特效都可以单独关闭。
- **声音**：音乐和音效分别有开关和音量滑块。
